
Lambda Functions
================
An AWS Lambda function is a piece of code that runs in the cloud without you managing any servers.
You write the code → upload it → AWS runs it automatically when something triggers it.

3. Create an ECS cluster (Fargate)
==================================
ECS - Elastic Container Service
Fully managed container orchestration service by AWS
	Lets you run Docker containers without managing servers (especially with Fargate)
	Handles scheduling, scaling, networking, and monitoring of your containers
	

ECS Cluster
	An ECS cluster is a logical grouping of resources that can run your containerized applications.
	It’s not a server itself, especially if you use Fargate (serverless mode)
	It keeps track of:
		Tasks → single running containers based on a task definition
		Services → long-running or scalable groups of tasks
		Networking (VPC, subnets, security groups)
		You can have multiple clusters for different environments (dev, staging, prod)

Need ECS service linked role


Go to ECS → Clusters → Create Cluster → Networking only (Fargate)
Name it: my-first-aws-app-cluster2 - first attempt with my-first-aws-app-cluster failed
Leave other settings default → Create


4. Create a Task Definition
===========================
Task definitions describe what containers to run.
ECS → Task Definitions → Create new Task Definition

Launch type: Fargate

Task size:

vCPU: 0.5 (sufficient for small apps)

Memory: 1 GB

Container definitions → Add container

Name: my-first-aws-app

Image: Paste your ECR image URI (869036203214.dkr.ecr.eu-north-1.amazonaws.com/my-first-aws-app)

Port mappings: 3009 TCP

Port name: doesn't matter. my-first-aws-app

Environment variables: optional for now

Click Add → Create - task definition successfully created


5. Create a Fargate service
===========================

ECS → Clusters → Select your cluster → Create → Service

Launch type: Fargate

Task definition: select the one you just created

Service name: my-first-aws-app-service

Number of tasks: 1 (can scale later)

Networking:

Cluster VPC: choose default VPC

Subnets: at least 2 public subnets

Auto-assign public IP: ENABLED

Security group: allow inbound TCP 3009 (or 80 if you want HTTP)

Click Next → Create Service

done

===
Container port

Definition: The port inside the Docker container that your application listens on.

Example: In your Dockerfile/NestJS app, you exposed port 3009:

app.listen(3009);


So your container port = 3009.

ECS/Fargate needs to know this so it can route traffic correctly inside the container.


Container port = port your app listens to inside the container (Dockerfile / app code). see main.ts

Port mapping = how the container port is exposed to the outside world (host / task ENI / load balancer)

For a simple single-container test, just set both to 3009 TCP, no need for fancy networking yet.
