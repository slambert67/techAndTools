Modules
=======
@Module

imports: 		other modules to use
controllers: 	controllers that handle incoming requests
providers: 		services or values available via DI
exports: 		providers that should be visible to importing modules

Singletons by default
Every module is automatically a shared module
Eagerly loaded by default


Controllers
===========
@Controller - class-level decorator. This class defines request-handling routes

Examples
	@Controller('users')			'users' is route prefix. Combines with @Get()
									@Get()				-> /users
									@Get(':id')			-> /users/:id
								
								
	@Controller({
		path: 'users',
		version: ['1', '2'],
		scope: Scope.Request		
	})								@Get()				/v1/orders and /v2.orders
									Creates new instance of Controller per request. Rare. Used if using request scoped providers


Controller Routing Methods
==========================
method level decorators

HTTP methods			Default status											
	@Get()				200 OK					Success response
	@Post()				201 Created				After creating a resource
	@Put()
	@Delete()			200 OK					After deletion					
	@Patch()			200 OK					After partial update
	@Options()
	@Head()
	@All()
	
Routing behaviour
	@Redirect()			Sends an HTTP redirect
	@HttpCode()			Override default status code. Does not override exceptions
							Delete			204 no content
							Async			202 accepted
	@Header()			Add a custom response header
	@Render()			Render a template (e.g., Handlebars, Pug)
	
Versioning/host
	@Version()			Specify an API version for this route
	@HostParam()		For routes using host-based routing (e.g. subdomains)
	
	
Examples
	@Get('docs')
	@HttpCode(302)
	@Redirect('https://docs.example.com')
	getDocs() {
	  return; // The redirect takes effect
	}

	@Version('2')
	@Post('users')
	@HttpCode(201)
	createUserV2() { return 'User created (v2)'; }


Controller Routing Method Parameters
====================================
parameter level decorators
NestJS parameter decorators let you extract specific parts of the incoming request directly into your route handler parameters — no need to access req manually.

Decorator				Category										Source							Description														Example
---------				--------										------							-----------														-------
URL params				@Param()										req.params						Path parameters/route parameters. Part of URL.					GET /users/123/orders/45	
																																										@Get('users/:userId/orders/:orderId')	
																																										getOrder(@Param('userId') userId: string, @Param('orderId') orderId: string)
																																									
																																									
Query String			@Query()										req.query						Query parameters. Appended to the URL after a ?					GET /products?category=books&sort=price&limit=10
																										Used for filtering, searching, sorting, pagination				@Get('products')
																																										findProducts(@Query('category') category: string, @Query('sort') sort: string, , @Query('limit') limit: number)
																																									
																																									
Headers					@Headers()										req.headers						Header parameters. Sent in the HTTP headers.					GET /profile
																										authentication, content type, API keys, metadata				Authorization: Bearer <token>, Content-Type: application/json
																																										@Get('profile')
																																										getProfile(@Headers('authorization') authHeader: string)
																																									
Body					@Body()											req.body						Sent in the request body (not the URL)							POST /users		   {"username": "alice","email": "alice@example.com"}
																										Used mainly in POST, PUT, PATCH requests when sending data		@Post('users')
																																										createUser(@Body() body: { username: string; email: string })
																																										
Cookies					@Cookies()																		Sent in the Cookie header
																										Often used for session IDs or authentication tokens				GET /dashboard		Cookie: sessionId=abcd1234; theme=dark
																																										@Get('dashboard')
																																										getDashboard(@Cookies('sessionId') sessionId: string)
																																									
Host Param				@HostParam()									dynamic hostname
Session					@Session()										session middleware
IP						@Ip()											req.ip
Request					@Req() / @Request()								raw request
Response				@Res() / @Response()							raw response
Next					@Next()											middleware-style next()
Uploaded files			@UploadedFile() / @UploadedFiles				via interceptors





We can use the library-specific (e.g., Express) response object
