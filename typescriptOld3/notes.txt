	How can you ensure a function parameter is a key of another object?
		Use a generic constraint with keyof
			function pluck<T, K extends keyof T>(obj: T, key: K): T[K] {
			  return obj[key];
			}

	How can you create a type that represents all possible values of an enum?
		Use keyof typeof.
		enum Direction { Up, Down }
		type DirectionType = keyof typeof Direction; // "Up" | "Down"

Type alias
    Can represent any kind of type - not just objects
        type Status = 'success' | 'error' | 'pending'; // union of string literals
        type ApiResponse<T> = T | Error;              // generic union
        type Point = [number, number];                // tuple
        type ID = string | number;                    // primitive union

    Can build new types from existing ones
    Type aliases work better with utility types and generics

Tree shaking
------------
Tree shaking is the process of removing unused (dead) code from your final JavaScript bundle.
It’s called tree shaking because your program’s dependency graph (imports, exports, functions, etc.) is like a tree, and the bundler shakes off the branches (code) that aren’t actually used.
Removes unused library functions
Only works 
	with ES modules (import / export)
	bundler supports static analysis
	Typescript compiled to a format that preserves ES modules
		{
			"compilerOptions": {
				"module": "ESNext",   // <-- Important
				"target": "ES2017"
			}
		}
